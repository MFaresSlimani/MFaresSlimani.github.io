# mfaresslimani.github.io

Personal site of Mohamed Fares Slimani: mobile engineer, AI researcher, university instructor.

- `index.html`: the résumé (about, experience, selected work, research, skills, education, languages, community, contact). The hero ID card has a machine-readable zone with real ICAO 9303 check digits that you can "scan".
- `work/`: all projects, with filters.
- `work/zakat.html`, `work/french-touch.html`, `work/optica.html`: case studies with small live demos (`demos.js`).

Plain HTML, CSS and JavaScript. No build step.

```bash
python -m http.server 8080
```

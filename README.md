Personal portfolio web application showcasing production mobile architectures, deep learning research, academic publications, and spoken languages.

- **Live Profile**: Mohamed Fares Slimani (Senior Mobile Engineer at ICOSNET SPA)
- **Research**: Computer Vision (FR-UNet on CHASE_DB1) & 3D Algerian Sign Language Avatar

- **Dynamic Hero Section**: Neural constellation interactive canvas, typewriter role switcher, verified engineering metrics.
- **Interactive Project Showcase**: Filterable project gallery with detailed modal breakdowns for Flutter Desktop (Windows), Flutter Mobile (Supabase/GetX), and deep learning research.

- **Direct Messaging Form**: Spam-protected AJAX contact form routing submissions directly to `faresslimani0@gmail.com`.
- **Responsive Architecture**: High-contrast dark glassmorphism design optimized across mobile, tablet, and desktop screens.

## 💻 Local Development

1. Clone or download the repository.
2. Open `index.html` with any local web server (e.g. Live Server or `python -m http.server 8080`).
3. No build tools or node dependencies required.
